Algorithm Explorer: Task Scheduler

Solve a real-world scheduling problem using four algorithmic approaches.

Problem Statement

Given a set of tasks, each with a duration and deadline, arrange the tasks in order when only one task can be done at a time and working hours are limited.

The goal is to create a schedule that fits the available time and minimizes total lateness—the sum of how late tasks finish past their deadlines.

Why It Matters

Students, employees, and event organizers often have more work than time and need to decide what to do first. A good schedule helps make deadlines visible and use limited working hours more thoughtfully.

Comparing these algorithms shows that a quick scheduling rule can be useful, but may not find the best order. It also makes the trade-offs between solution quality, running time, and memory easier to understand.

What the Program Computes

Enter each task's name, duration, and deadline, along with the total available working hours. Choose an algorithm to calculate and compare a task schedule.

  • The order in which tasks should be completed
  • Each task's start time and finish time
  • How late each task finishes (zero if it meets its deadline)
  • Total lateness across the schedule
  • Whether all scheduled tasks fit within the available hours
  • A short explanation and time and space complexity for the selected algorithm
