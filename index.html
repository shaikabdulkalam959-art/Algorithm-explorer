Algorithm Explorer: Task Scheduler

Solve a real-world scheduling problem using four algorithmic approaches.

The Problem

Students, employees, and event organizers need to complete tasks before their deadlines. Each task takes a certain amount of time, and only one task can be done at a time.

The app takes task names, durations, and deadlines, then creates a schedule. It calculates the completion time and lateness of every task.

Goal: Schedule all tasks without overlap and minimize the total lateness.
